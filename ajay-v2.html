Architecture & Supported Formats

AJAY Cipher is a Combinatorial-Permutation Hybrid Cryptosystem. It dynamically expands its security space based on payload size. Currently, it is strictly optimized for JPG, JPEG, and PNG formats, utilizing deep metadata scrambling to destroy image headers (IHDR, SOF, EXIF).

Forensic Impact: The "AJAY" Marker

If you uncheck the Include "AJAY" Marker toggle during encryption, the output file will lack any cryptographic signature. During standard forensic tests (magic-byte scanning), the file will appear as completely random noise or corrupted raw data, making it impossible to identify the cipher used.

CRITICAL: Human Errors (How it breaks)

The mathematical combinatorial space is unbreakable (it would outlive the universe to brute-force). However, SECURITY FAILS WHEN HUMANS FAIL. To maintain absolute secrecy, you MUST AVOID:

  • Key Leakage: Never share your .ajk.txt armored key over insecure unencrypted channels.
  • Weak Vault Passwords: The vault is only as strong as your password. A dictionary password allows local offline cracking of the vault.
  • Compromised Environment: Do not run this on a device infected with RAM-scraping malware or spyware.
  • Physical Coercion: No math can protect you if someone physically forces you to hand over the password (The $5 Wrench Attack).
